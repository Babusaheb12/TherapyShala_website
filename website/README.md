# TherapyShala Website

Welcome to **TherapyShala** — an on-demand spa and therapy platform connecting clients with professional therapists.

## Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** TailwindCSS 4
- **Animations:** Framer Motion & GSAP
- **Icons:** Lucide React

## Getting Started

### Prerequisites
Make sure you have Node.js installed.

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
